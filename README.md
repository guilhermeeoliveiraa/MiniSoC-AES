# MiniSoC-AES

### Aluno: João Oliveira

## Sobre o projeto

Este repositório foi desenvolvido no contexto de uma **capacitação promovida pelo CI-Expert**, com o objetivo de aplicar e consolidar conhecimentos relacionados ao desenvolvimento e à verificação de sistemas digitais.

O projeto MiniSoC-AES reúne atividades práticas realizadas durante a capacitação, servindo como ambiente para o desenvolvimento, a validação e o acompanhamento da evolução do projeto.

## Objetivos

- Aplicar os conhecimentos adquiridos durante a capacitação do CI-Expert.
- Desenvolver e verificar funcionalidades de sistemas digitais.
- Desenvolver e aplicar ambientes de **verificação UVM (Universal Verification Methodology)** para validar o comportamento do projeto.
- Praticar o uso de ferramentas e metodologias de desenvolvimento e verificação.
- Utilizar o Git e o GitHub para controle de versão e gerenciamento do histórico do projeto.
